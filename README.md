# 深空当铺：出货箱 Mod

**开发中，尚未达到可安装验收标准。** 当前编译成功不代表玩法已验证，请勿用于现有正式存档。

目标：通过王尔德的恩惠购买可移动出货箱，以材料独立升级容量，睡觉时统一出售箱内符合条件的货物。支持标签显示估值、赃物涉案金额及黑市声望规则。

## 当前状态

- 已建立 C# Mod 骨架、原生容器注册及中文设置声明。
- 已建立赃物减免和假标签声望处罚的纯计算函数。
- 购买、升级、夜间结算、调试新局赠送与保存集成仍在开发。
- 尚未进行游戏内验证，暂无正式发布版。

## 本机构建

将本源码目录放在游戏根目录下，执行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。
构建脚本引用上级游戏目录中的 Managed 程序集，使用 Windows .NET Framework C# 编译器。
输出为 `build/ShippingBin.dll`；当前输出仅供开发，不应视为可玩的成品。
