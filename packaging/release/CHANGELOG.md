# 变更记录 / Changelog

## 0.1.0 — 2026-11-16

首个发行候选（v0.1.0）。

### 新增

- 可移动、占背包 4x4 格的出货箱物品；四档容量 10x10 → 17x10 → 17x20 → 32x30（100 / 170 / 340 / 960 格），累计点数阈值 0 / 25 / 100 / 300。
- 睡觉时（`OnGoingSleepEarly`）一次性结算所有箱子；全箱先快照计划再提交，物品/金额/存档一致；关门与离开店铺不出售。
- 售价默认按当前状态显示估值的 0.8 倍，可配置；复用原版整树估值（含容器后代、锁后排除、`IGNORE_CHILD_VALUE`、商店事件）。
- 整根容器按一件物品出售；任一后代不可售则整根保留并在夜间报告说明原因。
- 赃物 / 违禁品分别开关（默认开）；涉案金额以原版基础值为基准，默认 x2；黑市声望 >=100 减半、>=200 全免（两个开关默认开，全免优先）。
- 假贴标复用原版 `VendingMachineHelper.IsMislabelled`，仅额外扣黑市声望（全晚实际销售额 1%，1–20）。
- 王尔德恩惠购买（2000 恩惠），空间不足预先拦截并原额回滚；买店后才显示，可配置提前显示。
- 升级材料 `junk`(1) / `scrap_metal`(2) / `metal_ingot`(5) 拖拽升级，点数每箱独立；形状迁移安全（取出→重塑→放回，失败回滚并记待扩容）。
- 物品说明悬停显示升级进度、下一档阈值与实际容量（读取失败显示「暂不可读取」）。
- 原版自动化料斗（`hopper_in` / `hopper_out`）保护；次日早间报告显示件数与销售额。
- 中英文官方本地化；配置项 8 项（2 个数值倍率 + 6 个开关，倍率使用原生数字输入框）。

### 修复

- 金属锭等材料无法拖到出货箱升级（原版白名单在 `MayTarget`/`CanTarget` 处否决，已加最小补丁）。
- 旧存档解码顺序导致的潜在越界丢物（工厂先建最大画布，读档后保守迁移）。
- 满级后迁移失败无法重试（改为持久待扩容，不重复消耗材料）。

### 已知限制

- 结算失败的「至多一次」记账恢复语义尚未在真实崩溃/断电场景下实机验证。
- 32x30 内容窗口在低分辨率下可能偏宽（原版窗口无滚轮）。
- 旧存档中 2x2 占格的箱子保持 2x2，不自动变 4x4。
- 料斗保护只覆盖原版两种料斗。
